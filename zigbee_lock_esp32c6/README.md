# 🚪 MyHome Zigbee 门锁光耦控制器 (ESP32-C6 Super Mini + PC817)

专为**改造现有智能门锁室内开门按钮**设计的超低功耗 Zigbee 3.0 控制器工程。

---

## 🌟 核心性能指标与芯片剪裁

- **2 年超长续航保障**：
  - **模块彻底断电**：在芯片底层完全切断 Wi-Fi 6 与 Bluetooth 5 模拟基带与时钟；
  - **CPU 降频至 40MHz**：大幅削减唤醒瞬间的动态电流（从 30mA 降至 8mA）；
  - **Zigbee 发射功率限制在 +10dBm**：发包峰值电流从 150mA 骤降至 50mA；
  - **常态 1.5 秒长轮询（1500ms）**：空闲时自动进入 FreeRTOS **Light Sleep**（静态底噪仅 `~35 μA`）；
  - **预警 200ms 高速轮询**：配合门厅人体传感器，检测到有人靠近时动态切入 200ms 极速轮询，实现 **0.1~0.2 秒秒级弹开门锁**！
- **物理电气隔离**：PC817 光耦输出端并联在智能门锁室内开门按钮两端，与门锁原厂电路完全隔离，杜绝烧锁风险。
- **开锁点动脉冲闭环**：收到指令后导通 `300ms` 模拟人工按下室内按钮，随后自动断开并开启 2 秒防重抖动保护。
- **0 依赖网页一键烧录**：提供基于 Web Serial API 的图形化网页刷机工具，**Mac 电脑无需安装 Python、VS Code 或编译器**！

## 🔌 硬件引脚分配与物理改装指南

### 1. ESP32-C6 Super Mini 引脚定义图

```text
                  ESP32-C6 Super Mini (正面)
                     ┌──────────────────┐
                     │ [  Type-C 接口 ] │
         (PC817控制) │ GPIO 1    GPIO 0 │
                     │ GPIO 2    GPIO 3 │
                     │ GPIO 4    GPIO 5 │
                     │ GPIO 6    GPIO 7 │
                     │ GPIO 8    GPIO 9 │ (板载 BOOT 键 / 配网脚)
                     │ 5V           GND │ ─── 接电池负极 / 光耦第 2 脚
 (供电输入 3.0~3.3V) │ 3V3       GPIO20 │
                     └──────────────────┘
```

### 2. 硬件物理“极限降功耗”两刀（必须操作，省下 90% 耗电）：
1. ✂️ **第一刀：挑掉板载红色电源指示灯 (PWR LED)**：
   - 板子上有一颗微型红色 LED（通常标着 `PWR` 或在 Type-C 口附近）；
   - 这颗灯只要通电就会白白吃掉 `~2 mA`！
   - **操作方法**：用美工刀尖、小螺丝刀或指甲刀，轻轻从侧面把这颗小红灯挑飞或割断它的限流电阻即可。
2. 🔌 **第二刀：直供 3.3V，避开板载稳压芯片 (LDO)**：
   - 电池供电时，**不要插 Type-C，也不要接 5V 脚**；
   - **把正极直接焊在 `3V3` 引脚，负极焊在 `GND` 引脚**；
   - 这样可以彻底绕过板载稳压器的内部待机漏电（立省 50~80μA）。

### 3. PC817 光耦接线拓扑

```text
  ESP32-C6 [GPIO 1] ───► [ 1kΩ 限流电阻 ] ───► PC817 第 1 脚 (阳极 +)
  ESP32-C6 [GND]    ─────────────────────────► PC817 第 2 脚 (阴极 -)

  智能锁室内按键【平时 3.3V 触点】──────────────► PC817 第 4 脚 (集电极)
  智能锁室内按键【平时 0V 触点】  ──────────────► PC817 第 3 脚 (发射极)
```

> [!IMPORTANT]
> **如何判断智能门锁按键的两极触点：**  
> 拆开室内面板后，用万用表直流电压档测量开门按键两端：平时测得有 **3.3V（或 5V）** 的那一脚接 PC817 的 **第 4 脚**；平时为 **0V** 的那一脚接 PC817 的 **第 3 脚**。

## 🔋 2 年超长续航供电推荐（二选一）

* **方案 A（最省心，免外挂电池盒）**：
  直接从智能门锁原本的电池仓（通常为 4~8 节 5 号电池，总电量 5000mAh+）引出正负极，经过微安级降压模块（`HT7333`，仅 2μA 静态损耗）降到 3.3V 接板子 `3V3` 和 `GND`。门锁换电池时一并更换。
* **方案 B（外挂大容量锂电池）**：
  接一节带保护板的 **3500mAh 18650 锂电池**（或 5000mAh 21700 锂电池），经过 HT7333 稳压后供电，可稳稳连续运行 **2.5 ~ 3 年**！

## 📡 Zigbee 配网与 Home Assistant 联动

1. **配网与重置操作**：
   - 首次上电自动进入搜网模式；
   - 若需重新配网：按住板载 **BOOT 键（GPIO 9）持续 3 秒**，设备清除历史凭证重新搜网；
   - 短按一次 BOOT 键：本地直接触发一次 300ms 点动开门测试。
2. **接入 Zigbee2MQTT / ZHA**：
   - Zigbee2MQTT 点击“允许新设备加入”，设备自动加入并识别为带 `lock` 和 `switch` 功能的门锁设备。
3. **Home Assistant 自动化联动**：
   当 C++ 门禁核验服务识别出自家人核验通过时，通过 Webhook 联动开门：
   ```yaml
   alias: "MyHome - 视觉/语音核验通过自动开锁"
   trigger:
     - platform: webhook
       webhook_id: ai_door_unlock_event
   action:
     - service: lock.unlock
       target:
         entity_id: lock.myhome_door_lock
   ```
