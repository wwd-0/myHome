# 🚪 MyHome Zigbee 门锁光耦控制器 (Pro Micro nRF52840 + PC817)

专为**改造现有智能门锁室内开门按钮**设计的超低功耗 Zigbee 3.0 硬件控制器。

---

## 🌟 核心特性与功耗参数

- **2 年超长电池待机**：基于 Zephyr RTOS **Tickless Idle** 深度休眠，芯片静态待机电流仅 `~3 μA`。
- **1.5 秒轮询平衡设计**：配置为 **Zigbee Sleepy End Device (休眠终端)**，每 `1.5 秒` 唤醒向网关拉取一次数据，在亚秒级开门体验与超长续航间取得最佳平衡。
- **物理电气隔离**：采用 **PC817 光电耦合器**，控制电路与智能门锁原厂主板完全电气隔离，绝对无共地干扰或烧锁风险。
- **点动自动复位闭环**：收到开门指令后，光耦导通 `300ms` 模拟人工按下室内按钮，随后自动断开并进入 `2秒` 冷却防抖期。
- **免安装 VS Code / 工具链**：支持 **UF2 拖拽烧录**（双击 RST 弹出 U 盘直接拷贝文件），并提供 **GitHub Actions 云端全自动编译**。

### 极性测试与接线步骤（非常重要）：
1. **拆开门锁室内面板**：找到室内的开门物理按钮（通常是 2 脚或 4 脚轻触按键）。
2. **万用表测电压**：
   - 万用表打到直流电压挡（20V 挡），黑表笔接地，红表笔测按键的两端：
   - 必定有一端平时呈现 **3.3V（或 5V）**的高电平，另一端呈现 **0V (GND)**。
3. **对应接线**：
   - 平时有 **3.3V 这一端** 接 PC817 的 **第 4 脚 (集电极)**；
   - 平时为 **0V 这一端** 接 PC817 的 **第 3 脚 (发射极)**；
   - *(注：光耦内部是光电三极管，集电极必须接高电压端，发射极接低电压端才能正确单向导通！)*

## 🔋 2 年续航供电方案推荐

1. **方案 A（最推荐，免额外电池盒）**：
   - 智能门锁本身通常使用 4 节或 8 节 5 号电池（标称 6V）。
   - 从锁电池仓引出正负极，经过一颗超低静态功耗 LDO（如 `ME6211` 或 `HT7333`，静态电流仅 `~2 μA`）降到 3.3V 接板子 VCC。门锁换电池时一并更换。
2. **方案 B（独立外置电池）**：
   - 外接 2 节 5 号**锂铁电池**（如劲量 Energizer L91 或南孚锂铁，两节共 3.0V~3.2V，容量 3000mAh，年自放电 < 1%），直连板子 VCC 与 GND。

## ⚡ 免 VS Code 固件获取与烧录

### 方式 1：GitHub Actions 云端自动编译（完全零安装）
1. 将当前项目 push 到你的 GitHub 仓库：
   ```bash
   git push origin v1
   ```
2. 进入 GitHub 仓库页面，点击顶部的 **Actions** 标签。
3. 在左侧看到 **`Build MyHome Zigbee Door Lock Firmware (UF2)`**，点击右侧的 **Run workflow**。
4. 等待 2~3 分钟编译完成，在构建详情页下方直接点击下载 **`myhome_zigbee_door_lock_uf2`** 压缩包，解压即可得到 `zephyr.uf2`！

### 方式 2：双击烧录进开发板
1. 用 Type-C 数据线将 Pro Micro nRF52840 连接到电脑。
2. 用一根小导线或镊子，**快速双击短接 RST 和 GND 两次**。
3. 电脑会像插上 U 盘一样弹出一个名为 **`NICENANO`** 或 **`NRF52BOOT`** 的磁盘盘符。
4. 直接将下载好的 **`zephyr.uf2`** 拖进该磁盘！
5. 磁盘进度条走完后会自动消失，板载指示灯常亮 2 秒，表示烧录成功并开始工作。

## 📡 Zigbee 配网与 Home Assistant 联动

1. **进入配网状态**：
   - 首次烧录后会自动开始搜网。
   - 若需重新配网：将引脚 `P0.20`（丝印 `020` / `D3`）与 `GND` **短接 3 秒以上**，板载指示灯快速闪烁，清除历史配网凭证并重新开始配网。
2. **加入网关**：
   - 在 **Zigbee2MQTT** 控制台右上角点击 **「允许所有设备加入」**。
   - 几秒内即可看到新设备加入，设备型号识别为 `ZB-DoorLock`。
3. **Home Assistant 自动化开门配置**：
   - 当 C++ 视觉/声纹服务识别出自家人开门时，通过 HA 自动化直接触发开门：
   ```yaml
   alias: "MyHome - 人脸/手势/语音核验通过自动开门"
   trigger:
     - platform: webhook
       webhook_id: ai_door_unlock_event
   action:
     - service: lock.unlock
       target:
         entity_id: lock.myhome_door_lock
   ```
